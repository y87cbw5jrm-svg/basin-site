# Basin

A market dynamics observatory for the S&P 1500 and the Dow Jones Global Titans 50:
attractors and flow, renormalization, information and transfer entropy, regimes,
early warnings, CEO backgrounds, and shovel-seller and trend filters with
point-in-time backtests.

Open the site: https://y87cbw5jrm-svg.github.io/basin-site/

This repository holds only the built website and its precomputed data (prices from
Yahoo Finance, fundamentals and proxy statements from SEC EDGAR, constituents from
Wikipedia and SPDR / iShares fund holdings, biographies from Wikidata), as of the
snapshot date shown in the site's sidebar. It is not investment advice.
